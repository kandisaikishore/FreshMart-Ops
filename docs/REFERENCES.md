# Requirements and security references

1. Government of India, CBIC — GST invoice rules: https://cbic-gst.gov.in/gst-invoice-rules.html
   Used to identify invoice fields and the need to configure invoicing for the registered business. This prototype does not certify GST compliance.
2. OWASP — Authentication Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html
   Reference for production authentication requirements.
3. OWASP — Session Management Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html
   Reference for HTTPS, session lifecycle and invalidation.
